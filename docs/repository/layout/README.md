Use this subtree to locate durable project areas and distinguish tracked canon
from ignored runtime output.

## Read This Section When

- You need to add, move, or remove a top-level path.
- You need to know which paths are durable source versus local output.
- You need a table of contents for repository layout docs.

## Protected Canon

- `docs/` is the protected project intent.
- Files outside `docs/` may be replaced when needed to satisfy the canon.
- Ignored local output is evidence input only unless summarized into `docs/`.
