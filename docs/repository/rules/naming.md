# Naming

Owner: `docs/repository/rules/naming.md`.
State: canonical documentation.

## Stable Names

- Avoid numbered stability labels for repo-owned concepts.
- New local APIs use unnumbered route names.
- External route names such as `/v1/models`, external API URLs, and runtime
  fields like `cuda_driver_version` are allowed only where exact names are
  required.

## Discouraged Wording

- Avoid stale claims that imply accepted decoder completion before evidence.
- Avoid legacy-preservation language for removed behavior.
- Avoid broad status words when a precise backend, report field, or gate is
  available.
