# Native CMake

Owner: `native/cmake/README.md`.
State: canonical documentation.


## Purpose

This directory holds small CMake fragments used by the native CUDA build.

## Contents

- [NativeSources.cmake](NativeSources.cmake): source-file lists for native
  static libraries.
- [NativeTargets.cmake](NativeTargets.cmake): native executable targets.
- [NativeContractTargets.cmake](NativeContractTargets.cmake): native contract
  and check executable targets.
- [NativeTests.cmake](NativeTests.cmake): CTest gates.
