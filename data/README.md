# Data

Owner: `data/README.md`.
State: canonical documentation.


## Purpose

This ignored runtime tree stores generated corpora, checkpoints, model exports,
agent transcripts, memory, and temporary workspaces.

## Contents

- [.gitkeep](.gitkeep): keeps the directory present in fresh clones.
- `train/tokenizer/tokenizer.json`: generated by
  `docker compose --profile corpus run --build --rm corpus build-tokenizer`.
- `train/datasets/packed/train-causal_lm_full-seq1024`: generated by
  `docker compose --profile corpus run --rm corpus build-public-pretrain-cache`.

## Rules

- Runtime artifacts belong here, not in source directories.
- Commit only this README and `.gitkeep` from this tree.
- Treat local contents as disposable unless a runbook explicitly promotes them.
- Do not treat a cache path as accepted evidence until
  `lkjai-native-packed-cache validate` passes against the exact source,
  tokenizer, and native decoder config.
